# Справочник протоколов

Этот скилл — библиотека фактов и шаблонов. Правило пользования: **статусы достоверности обязательны**. Каждый протокол размечен:
- `wire-verified` — подтверждено логом с живого ЭБУ (эталонный пример прилагается);
- `code-grounded` — извлечено из кода/трасс оригинального ПО;
- `hypothesis` / «не подтверждено» — по вторичным источникам или предположение.

## Как расширять справочник

Новые протоколы добавляются по `references/TEMPLATE-protocol.md`; обязательные разделы и правила статусов — там же. Не удаляй пометки «не подтверждено»: они защищают от повторения чужих ошибок (пример: «кадр `80 F1 10 81 C1 EA 8F`» из интернета — невалиден по стандарту, см. kwp2000-iso14230.md §примеры).

## Ключевые «грабли» в справочниках (не путать!)

- **KWP2000**: биты 7–6 FMT — режим адресации (10=physical, 11=functional), младшие 6 бит — длина **data-поля**; 0 → отдельный байт длины. Чексумма — сумма ВСЕХ байт кроме CS, mod 256.
- **ISO 9141-2**: поля длины в кадре НЕТ (ниббл 0x8 в 0x68/0x48 не является длиной); конец кадра — по межбайтовому таймауту.
- **KWP1281**: чексуммы нет вообще — каждый байт сопровождается комплементом `0xFF−b`; инициализация адресом 0x01.
- **DS2**: длина — полная длина кадра (включая addr и cks); чексумма XOR **без** последнего байта.
- **EDIABAS** — это не проводной протокол, а «зонтик» (концепции ADS/DS1/DS2/BMW-FAST/D-CAN/ENET + SGBD-скрипты поверх). «Протокол EDIBUS/EDIABAS» в разговоре = его концепции и трассы.
