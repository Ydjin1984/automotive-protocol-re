# Старый парк: J1850, CCD, SCI, MUT, ALDL

Протоколы машин 1980-х–2000-х. Часть из них встречается в меню диагностических сканеров («DS2», «EDIBUS»-подобные названия) и в задачах реверса старых дилерских программ. Внимание: «DS2» в BMW-контексте — это BMW DS2 (`ds2-bmw.md`); отдельного публично документированного «Chrysler DS2» нет (у Chrysler — CCD/SCI/PCI).

## 1. SAE J1850 PWM (Ford SCP)
- **41.6 кбит/с**, два провода: pin 2 (Bus+) и pin 10 (Bus−), уровни +5 В.
- Сообщение ≤12 байт включая CRC; арбитраж CSMA/NDA; в OBD-ролях: запрос `61 6A F1`, ответ `41 6B xx`.

## 2. SAE J1850 VPW (GM Class 2)
- **10.4 кбит/с** (в части источников 41.6), один провод (pin 2), в покое низкий, высокий ≈ +7 В, порог решения +3.5 В.
- ≤12 байт с CRC, CSMA/NDA; OBD-заголовки `68 6A F1` / `48 6B xx`.

## 3. Chrysler CCD (C2D)
- Витая пара: DLC pin 3 (CCD+), pin 11 (CCD−); **7812.5 бит/с** (кварц 1 МГц / 128).
- До 13 модулей; арбитраж по ID-байту с «read back and compare» (доминантный 0 / рецессивный 1).
- Кадр: SOF → header/ID → данные → CRC → In-Frame Response → EOF. Годы 1989–1998 (до 2003 на части моделей).
- Инструменты: DRB II / DRB III. Опенсорс для разбора: laszlodaniel/ChryslerScanner.

## 4. Chrysler SCI
- Точка-точка, half-duplex **7812.5 бод** после reset (каждый байт запроса **эхом** возвращается — как у K-line), high-speed режим **62500 бод** full-duplex.
- NRZ: «1» > 4.0 В, «0» < 1.0 В; idle = 10+ битовых интервалов «1», break = 10+ «0».
- Применение: PCM/TCM (дилерский DRB); до 2003 — пины 6/14.

## 5. Mitsubishi MUT-II / MUT-III (MMC SCI)
- **15625 бод**, 8N1, LSB-first, K-line 12 В/0 В.
- **5-baud init с адресом 0x01** (не 0x33!), затем выбор системы; ответ ЭБУ `C0 55 EF 85` (часть источников цитирует `55 EF 85`).
- Адреса систем: 0x00 ECU, 0x01 TCU, 0x02 ECS, 0x04 ABS, 0x08 SRS, 0x0B AYC, 0x19 TPMS, 0x1A камера, 0x83 рулевое, 0x85 TCL, 0x89 иммобилайзер, 0x8A SWS, 0x91 HBB, 0x92 SS4II.
- Примеры PID-формул: 0x21 обороты = A×31.25; 0x2F скорость = A×2; 0x14 АКБ = A×0.0733; 0x1A MAF = A×6.29; 0x06 УОЗ = A−20.
- MUT-II «ISO method» — это ISO 9141 (pin 7); MMC SCI — свои пины. Упоминания «7812.5 бод» для MUT — артефакт эхо/двух байт на элемент (**расхождение**, не битрейт).

## 6. GM ALDL (Assembly Line Diagnostic Link)
- Два режима: 160 бод (односторонний PWM, ранние ECU) и **8192 бод** (двунаправленный, request-driven).
- Кадр 8192 бод: idle 10+ «1»; ID (0xF0 поллинг; 0xF4/0xF5/0xF7 у части ECM); **length = 0x55 + N data-байт** (0x55 при N=0, 0x56 = +1, 0x57 = +2); mode-байт; data; контрольная сумма — **two's complement суммы** (часть источников говорит one's complement — **расхождение**).
- Примеры: `F0 56 01 CS` (Mode 1), с номером сообщения — `F4 57 01 00 CS`.

## 7. K-line общее (для всех «однопроводных»)

- Идле — высокий (+12 В через подтяжку), передача — прижатие к земле; **эхо обязательно** (полудуплекс); TX и RX физически на одном узле через трансивер.
- Питание стенда: +12 В, земля общая с тестером; уровень приёма — через L9637D/MC33290 или делитель.
- Пин 7 J1962 = K, пин 15 = L, пин 8 = K-BMW (DS2 на E-серии) — проверяй распиновку конкретной машины.
